1. Project Overview
The Automated Aquarium Management System is an IoT project that helps aquarium owners monitor and manage water conditions automatically. Sensors connected to an ESP32 microcontroller measure parameters such as pH, temperature, turbidity, and water level. Data is sent to a web application and mobile dashboard, allowing owners to check conditions remotely, receive alerts, and reduce manual maintenance.

2. Main Features
Staff/owner login for secure access

Continuous monitoring of pH, temperature, turbidity, and water level

Automatic fish feeding via servo motor

Real‑time IoT monitoring through Blynk mobile app

Alert notifications for abnormal conditions (unsafe pH, high/low temperature, dirty water, low water level)

Remote monitoring via smartphone or PC

Automatic control logic (ESP32 reacts to sensor data)

User‑friendly dashboard for quick status checks

3. Technologies Used
ESP32 → Main microcontroller

IoT + Wi‑Fi → Internet connectivity for remote monitoring

pH Sensor → Measures acidity/alkalinity

DS18B20 Temperature Sensor → Measures water temperature

Turbidity Sensor → Detects water clarity

Float Sensor → Monitors water level

Servo Motor → Automatic fish feeder

Blynk App → Mobile dashboard for sensor readings

Telegram Notifications → Alerts for abnormal conditions

Arduino IDE + Embedded C/C++ → Programming environment and language
